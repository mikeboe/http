# http

A thin VS Code HTTP client: Yaak-style split-screen editor, requests stored as YAML files in your repo, OpenAPI import, and a format simple enough for coding agents to write.

Status: design. See [docs/superpowers/specs/2026-10-22-http-client-design.md](docs/superpowers/specs/2026-10-22-http-client-design.md) and the [UI mockup](mockups/layout.html).
